# Stream Tribunal

[![License: MIT](https://img.shields.io/badge/license-MIT-blue?style=flat-square)](LICENSE)

Суд над зрителями прямо в эфире. Чат пишется в очередь, ты выбираешь одного на скамью, он отвечает в чате, ты защищаешь его с микрофона, а судья-ИИ выносит вердикт. Виновного ждёт выбранная тобой кара.

## Быстрый старт

1. Скачайте `StreamTribunal-windows-amd64.zip` из Releases и распакуйте в любую папку.
2. Запустите `StreamTribunal.exe`. Откроется пульт: `http://localhost:7890`.
3. Вставьте ключ Groq/Cerebras в Настройках → Мозг (без ключа суд говорит заготовками).
4. В OBS добавьте источник «Браузер» с URL `http://localhost:7890/overlay`, размер 1920x1080, включите «Управлять звуком через OBS».
5. Зрители пишут `!court`, ты жмёшь «Случайный на скамью» в Режимах. Суд пошёл.

Голос работает из коробки, без ключей: синтез через Edge TTS, при обрыве сети откат на локальный движок.

## Как идёт дело (около 2 минут)

1. **Скамья.** Зритель из очереди встаёт перед судом, судья зачитывает обвинение и задаёт вопрос.
2. **Показания.** Подсудимый отвечает в чате (~25 секунд), его реплики висят плашкой в оверлее.
3. **Защита.** Ты — адвокат: говоришь в микрофон, вкладка пульта слушает и передаёт слова судье.
4. **Протест.** Судья перебивает встречным панчлайном с грохотом молотка.
5. **Совещание и приговор.** Судья решает ВИНОВЕН/НЕВИНОВЕН и бьёт три раза. Кара — та, что выбрана в пульте.

## Режимы

- **01. Суд над зрителем (дефолт).** Очередь `!court`, доносы `!snitch`, признание `!crime`.
- **02. Суд над стримером (редкое событие).** Только вручную или за платину-донат.
- **03. Unban-суд.** Заявки на разбан из Twitch, кнопки пишут решение сразу в Helix.

## Команды чата

| Команда | Что делает |
|---|---|
| `!court [за что]` | Встать в очередь на скамью |
| `!leave` | Выйти из очереди |
| `!crime <проступок>` | Признание: сразу в дело, минуя очередь |
| `!snitch <текст>` | Донести на подсудимого |

## Кара

Выбирается в пульте и применяется к виновному: Помиловать, мут 60/300 (или свой срок), бан. Дефолт — мут 90 секунд. Боту нужны права модератора, иначе Twitch отклонит кару (ошибка видна в `/api/status` как `chat_mod_error`).

## Twitch

Чтение чата и ответы бота:

1. Выпустите токен со скоупами `chat:read chat:edit` (например, через twitchtokengenerator).
2. Впишите в `config.yaml`:

```yaml
twitch:
  channel: "ваш_канал"
  nick: "ник_бота"
  token: "oauth:..."
```

Без токена модуль чата молча выключен, остальное работает. Для Unban-суда добавьте `client_id`, `broadcaster_id` и скоупы `moderator:read:unban_requests` + `moderator:manage:unban_requests`.

## Донаты

DonationAlerts подключается токеном виджета (`donations.donationalerts.token` или env `DONATE_TOKEN`, берётся из `?token=` любой ссылки виджета алертов). Сокет виджета пока бета: каждое событие пишется в лог, гарантированно работают вебхук и симуляция ниже.

- **DonatePay**: API-ключ с `donatepay.ru/page/api` (`donations.donatepay.api_key` или env `DONATEPAY_API_KEY`). Официальный Centrifugo-сокет, белый IP не нужен.
- **Twitch Bits**: EventSub WebSocket, нужен токен со скопом `bits:read` плюс `twitch.client_id` и `twitch.broadcaster_id`. Порог по валюте `BITS` (дефолт 200).
- **Любая другая платёжка**: `POST /api/donate` с JSON `{"donor","amount","currency","message"}`. Сюда цепляются StreamElements, Streamlabs и что угодно с вебхуками.

Порог на суд задаётся отдельно для каждой валюты (`donations.min_amounts`, остальные через `donations.default_min`). Донат ниже порога просто попадает в память суда. Если суд уже идёт, донат приобщается как показание свидетеля и зачитывается отдельной репликой. Донат со словом «взятка» качает весы к оправданию, судья переобувается вслух.

Платиновый донат (`donations.platinum_min`) открывает редкое дело над стримером.

## Конфиг

Всё лежит в `config.yaml` (пример: `config.default.yaml`), секреты можно держать в env. Ключи, токены, провайдер ИИ и движок речи правятся прямо в панели и сохраняются в `config.yaml` без рестарта.

| Ключ | Env | Что делает |
|---|---|---|
| `server.port` | — | Порт панели и оверлея, дефолт 7890 |
| `server.secret` | `TRIBUNAL_SECRET` | Секрет на запуск суда и смену настроек |
| `ai.provider` | — | `groq`, `cerebras` или `ollama` |
| `ai.api_key` | `GROQ_API_KEY` / `CEREBRAS_API_KEY` | Без ключа включается mock-режим |
| `twitch.token` | `TWITCH_TOKEN` | Токен чата, без него модуль чата выключен |
| `tts.engine` | — | `edge` по дефолту, `silero` локально живой, `piper` оффлайн |
| `courtroom.judge_style` | — | `strict` сухой судья, `cynical` продажный |
| `courtroom.defense_sec` | — | Окно защиты-адвоката, дефолт 20 |
| `courtroom.testimony_sec` | — | Окно показаний подсудимого, дефолт 25 |
| `game.memory_path` | — | Куда писать память судов, дефолт `data/memory.json` |

Пульт суда: `GET /api/dock`, `POST /api/dock/pick`, `POST /api/dock/skip`, `POST /api/punish`. История: `GET /api/history`, профиль: `GET/PUT /api/profile`. Ручной запуск: `POST /api/trial`, статус: `GET /api/status`.

## Silero (живой голос локально)

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install numpy
python tools/silero_sidecar.py   # http://127.0.0.1:7892
```

В `config.yaml`: `tts.engine: silero`. Модель `v5_ru.pt` (~87 МБ) скачается сама при первом запуске.

## Ограничения

- Вердикты и кары шуточные; бан/мут требуют модерки бота.
- Edge TTS требует интернет, оффлайн голос суше (Piper) или писк-заглушка если нет модели.
- Русские ударения в омографах иногда плывут, плюсы-ударения понимает только Silero.

## Сборка из исходников

```bash
make build   # собирает фронт (web/frontend), оверлей и бинарь dist/StreamTribunal
```

Пульт (`web/dashboard/`) закоммичен ради `go:embed` — после правок в `web/frontend/src` выполни `make frontend` и коммить обновлённый бандл вместе с исходниками.
