# Stream Tribunal

[![License: MIT](https://img.shields.io/badge/license-MIT-blue?style=flat-square)](LICENSE)

Суд над стримером прямо в эфире. ИИ-прокурор зачитывает обвинение, чат голосует, вердикт прилетает в OBS за секунды.

## Быстрый старт

1. Скачайте `StreamTribunal-windows-amd64.zip` из Releases и распакуйте в любую папку.
2. Запустите `StreamTribunal.exe`. Откроется панель: `http://localhost:7890`.
3. В OBS добавьте источник «Браузер» с URL `http://localhost:7890/overlay`, размер 1920x1080, включите «Управлять звуком через OBS».
4. Нажмите «Начать процесс» в панели. Суд пошел.

Голос работает из коробки, без ключей: синтез через Edge TTS, при обрыве сети откат на локальный движок.

## Как это выглядит

Смерть в Minecraft, спам `!sue` в чате или кнопка в панели открывает дело. Прокурор объявляет статью и разносит подсудимого, реплики идут голосом в эфир с субтитрами. Дальше чат голосует `!guilty` / `!innocent`, бот считает и объявляет вердикт. Ничья трактуется в пользу подсудимого.

Суд помнит прошлое: рецидивы, серии вердиктов, заводил чата и донаты. Портрет стримера (черты, мемы, строгость) правится в панели и подмешивается в обвинения.

## Режимы

- **Minecraft.** Вотчер `latest.log`: лава, крипер, падение, утопление открывают дело сами. Путь к логу задается в конфиге.
- **Just Chatting.** Без игры: кнопка, пресеты и команды чата.
- **Суд над зрителем.** Только по желанию: зритель пишет `!crime <проступок>`.

## Twitch

Нужны чтение чата и ответы бота:

1. Выпустите токен со скоупами `chat:read chat:edit` (например, через twitchtokengenerator).
2. Впишите в `config.yaml`:

```yaml
twitch:
  channel: "ваш_канал"
  nick: "ник_бота"
  token: "oauth:..."
```

Без токена модуль чата молча выключен, остальное работает.

Автосуд по спаму: `courtroom.sue_threshold` штук `!sue` за минуту. Кулдаун между автосудами 3 минуты, чат не заддосит заседание.

## Донаты

DonationAlerts подключается токеном (`game.donate_token` или env `DONATE_TOKEN`). Донат с текстом попадает в контекст обвинения одной язвительной фразой, крупный донат помечается как взятка. Без токена работает оффлайн.

## Конфиг

Все лежит в `config.yaml` (пример: `config.default.yaml`), секреты можно держать в env.

| Ключ | Env | Что делает |
|---|---|---|
| `server.port` | — | Порт панели и оверлея, дефолт 7890 |
| `server.secret` | `TRIBUNAL_SECRET` | Секрет на запуск суда и смену профиля, без него локально открыто |
| `ai.provider` | — | `groq`, `cerebras` или `ollama` |
| `ai.api_key` | `GROQ_API_KEY` / `CEREBRAS_API_KEY` | Без ключа включается mock-режим для проверки тракта (кроме ollama) |
| `twitch.token` | `TWITCH_TOKEN` | Токен чата, без него модуль чата выключен |
| `tts.engine` | — | `edge` по дефолту, `piper` оффлайн, автофолбэк флагом |
| `game.minecraft_log` | — | Путь к `latest.log`, пусто значит выключено |
| `game.memory_path` | — | Куда писать память судов, дефолт `data/memory.json` |

История судов и профиль: `GET /api/history`, `GET/PUT /api/profile`. Ручной запуск: `POST /api/trial`, статус: `GET /api/status`.

## Ограничения

- Вердикты и наказания шуточные, управления сценами OBS пока нет, только оверлей.
- Edge TTS требует интернет, оффлайн голос суше (Piper) или писк-заглушка если нет модели.
- RVC-преображение тембра и облачные премиум-голоса в этот релиз не вошли.
- Русские ударения в омографах иногда плывут, лечится перефразированием статьи.
