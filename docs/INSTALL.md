# Руководство по установке и первому запуску

Подробная инструкция по установке Stream Tribunal: быстрый запуск готового исполняемого файла на Windows, настройка звука и оверлея в OBS Studio, сборка из исходников и чеклист решения неполадок.

---

## 1. Системные требования

| Компонент | Минимальные требования | Рекомендуемые |
| :--- | :--- | :--- |
| Операционная система | Windows 10/11 (64-bit), Linux x86_64, macOS Apple Silicon | Windows 10/11 (64-bit) |
| Оперативная память | 256 МБ RAM | 512 МБ RAM (при локальном Silero TTS: 1.5 ГБ) |
| Свободное место на диске | 80 МБ (один файл .exe) | 300 МБ (при кэшировании моделей озвучки) |
| Программное обеспечение | OBS Studio версии 28.0 или новее | OBS Studio 30+ с поддержкой Browser Source |
| Браузер | Chrome, Edge, Firefox, Brave | Chrome или Edge (для Web Speech API микрофона) |
| Микрофон | Любой рабочий микрофон | Микрофон стримера для живой речи защиты |

## 2. Экспресс-установка на Windows (один .exe файл)

Я собрал приложение в единый исполняемый файл. Вам не нужно устанавливать Git, Go, Node.js, Python или поднимать контейнеры Docker. Весь сервер, интерфейс пульта и графический оверлей уже встроены внутрь бинарника.

### Шаг 1: Скачивание
1. Перейдите в раздел релизов репозитория на GitHub: [Releases](https://github.com/ivanchik-byte/TwitchCourt/releases).
2. Скачайте архив `StreamTribunal-windows-amd64.zip`.
3. Распакуйте архив в удобное место на диске (например, в папку `C:\StreamTribunal\`).

### Шаг 2: Первый запуск
1. Дважды кликните по файлу `StreamTribunal.exe`.
2. Появится консольное окно сервера, сообщающее о старте локального сервиса на порту 3236. Не закрывайте это окно во время трансляции.
3. В браузере перейдите по адресу: `http://localhost:3236`. Перед вами откроется пульт управления судом.

### Шаг 3: Настройка нейросети
1. В левом меню пульта откройте вкладку «Настройки» -> «Языковая модель».
2. Вставьте ваш API-ключ. Я рекомендую использовать бесплатный Groq (модель `llama-3.3-70b-versatile` отвечает за 300-500 мс, что идеально для динамичного стрима). Также поддерживаются Cerebras, OpenRouter, OneRouter и локальные серверы Ollama. Без настроенной нейросети суд не стартует — автономного режима нет.

## 3. Настройка оверлея в OBS Studio

Чтобы зрители трансляции видели зал суда, подсудимых и субтитры:

1. Откройте OBS Studio на сцене общения или игры.
2. В панели «Источники» нажмите кнопку «+» и выберите «Браузер» (Browser).
3. Укажите название: `Суд (Оверлей)`.
4. В свойствах источника задайте:
   * **URL:** `http://localhost:3236/overlay`
   * **Ширина:** `1920`
   * **Высота:** `1080`
   * **FPS:** `60`
   * **Галочка:** «Управлять звуком через OBS» (обязательно включите).
   * **Галочка:** «Выгружать сцену, когда она невидима» (снимите, чтобы не терять соединение).
5. Нажмите «ОК».

### Вывод звука судьи в наушники:
1. В главном окне OBS в блоке «Микшер аудио» нажмите шестеренку у источника `Суд (Оверлей)`.
2. Выберите пункт «Расширенные свойства аудио».
3. Для источника `Суд (Оверлей)` переключите «Мониторинг аудио» в режим **«Мониторинг и вывод»**.
4. Теперь голос судьи будет слышен зрителям на трансляции и вам в наушниках.

## 4. Подключение к Twitch (Бот и модерация)

Для автоматического чтения очереди подсудимых из чата:

1. Откройте вкладку «Настройки» -> «Twitch» в пульте.
2. Укажите имя вашего канала (например, `shroud`).
3. Укажите логин бота (например, имя вашего второго аккаунта или основного канала).
4. Получите OAuth токен для бота с правами чтения и отправки сообщений (`chat:read`, `chat:edit`). Токен можно сгенерировать через официальный генератор Twitch Chat Token.
5. Назначьте учетную запись бота модератором на вашем канале командой `/mod <логин_бота>` в чате Twitch.

## 5. Сборка из исходников (Для разработчиков)

Если вы хотите внести изменения в исходный код на Go или интерфейс React:

### Необходимые инструменты:
* Go версии 1.23 или новее
* Node.js версии 20 или новее (с менеджером npm)
* Git

### Порядок сборки:
```bash
# Клонируйте репозиторий
git clone https://github.com/ivanchik-byte/TwitchCourt.git
cd TwitchCourt

# Соберите фронтенд пульта управления
cd web/frontend
npm install
npm run build
cd ../..

# Запустите модульные тесты
go test -v ./internal/...

# Соберите исполняемый файл для вашей платформы
go build -ldflags="-s -w" -o dist/StreamTribunal ./cmd/server
```

### Кросс-компиляция бинарника Windows из Linux:
```bash
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -ldflags="-s -w" -o dist/StreamTribunal.exe ./cmd/server
```

## 6. Чеклист решения частых проблем

| Проблема | Причина | Решение |
| :--- | :--- | :--- |
| Судья говорит, но стример не слышит голос в наушниках | В OBS включен только вывод в стрим без мониторинга | Откройте расширенные свойства аудио в OBS и выберите «Мониторинг и вывод» для браузерного источника. |
| Оверлей черный или не обновляется | Порт занят другим приложением или заблокирован брандмауэром | Проверьте порт в консоли сервера (по умолчанию 3236). Откройте `http://localhost:3236/overlay` в обычном браузере. |
| Бот не отправляет приговоры в чат Twitch | Неверный OAuth токен или бот забанен в чате | Проверьте токен в пульте. Выдайте боту права модератора командой `/mod <логин>` в чате. |
| Голос судьи прерывается или молчит | Ограничение облачного Edge TTS со стороны провайдера | В настройках включите Silero TTS (локальный Python микросервис) либо используйте Piper ONNX. |
| Микрофон стримера не распознает речь | Браузер не получил доступ к микрофону | Разрешите доступ к микрофону во всплывающем окне браузера при открытии пульта `http://localhost:3236`. |
| Кнопка паники F12 открывает DevTools в браузере | Горячая клавиша перехвачена окном браузера | Нажимайте F12 при активном окне OBS, либо переназначьте клавишу на `F9` или `Escape` в `config.yaml`. |
