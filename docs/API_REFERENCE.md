# Справочник REST и WebSocket API

Документация по всем публичным и служебным интерфейсам взаимодействия с сервером Stream Tribunal.

---

## 1. Аутентификация

Если в `config.yaml` задан параметр `server.secret` (или переменная окружения `TRIBUNAL_SECRET`), все изменяющие запросы требуют авторизации.

Способы передачи секрета:
* HTTP заголовок: `X-Tribunal-Secret: ваш_секрет`
* Параметр строки запроса: `?secret=ваш_секрет` (используется для WebSocket и браузерных источников OBS)

При неверном или отсутствующем ключе сервер возвращает статус `401 Unauthorized`.

## 2. Эндпоинты управления судебным процессом

### POST /api/trial
Принудительно открывает новое судебное заседание.

* Тело запроса (JSON):
```json
{
  "defendant": "username",
  "crime": "Слив катки на решающем раунде",
  "viewer": true
}
```
* Ответ: `200 OK` с объектом дела. Если суд уже занят, возвращается `409 Conflict`.

---

### POST /api/dock/pick
Выбирает кандидата из очереди `!court` и сажает его на скамью подсудимых.

* Тело запроса (JSON):
```json
{
  "nick": "username"
}
```
* Если поле `nick` пустое, сервер выбирает случайного зрителя из текущей очереди.

---

### POST /api/dock/skip
Сбрасывает текущее дело и освобождает скамью подсудимых.
* Метод: `POST`
* Ответ: `200 OK` с очищенным состоянием очереди.

---

### POST /api/defense
Передает аргумент защиты стримера в контекст текущего дела (используется микрофоном пульта управления).

* Тело запроса (JSON):
```json
{
  "author": "стример",
  "text": "У подсудимого есть алиби, в момент инцидента он перезагружал роутер!"
}
```
* Ответ: `200 OK` при успешном добавлении в материалы дела.

---

### POST /api/moderate
Исполняет команду прямой модерации подсудимого в Twitch чате.

* Тело запроса (JSON):
```json
{
  "user": "username",
  "action": "ban",
  "secs": 60,
  "reason": "Решение суда: нарушение правил"
}
```
* Допустимые значения `action`:
  * `ban`: перманентная блокировка в чате.
  * `timeout`: временный мут на `secs` секунд (по умолчанию 60).
  * `pardon`: снятие блокировки и ограничений (`/unban`).

---

### POST /api/punish
Задает меру наказания, которая применится при следующем обвинительном вердикте.

* Тело запроса (JSON):
```json
{
  "kind": "timeout",
  "secs": 300
}
```
* Допустимые значения `kind`: `timeout`, `ban`, `pardon`.

---

### POST /api/say
Заставляет судью произнести произвольный текст в эфире с генерацией анимации.

* Тело запроса (JSON):
```json
{
  "text": "Суд объявляет перерыв на пять минут!"
}
```

---

### POST /api/panic
Экстренно глушит воспроизведение звука, прерывает ожидание ответа модели и переводит систему в статус ожидания IDLE.
* Метод: `POST`
* Ответ: `200 OK`

## 3. Эндпоинты колоды дел (cases.yaml)

### GET /api/cases
Возвращает список всех зарегистрированных судебных дел, текущие веса и список сыгранных идентификаторов.

---

### POST /api/cases/draw
Вытягивает следующее случайное дело из колоды с учетом настроенных весов и передает его в игровой движок.

---

### POST /api/cases/generate
Запускает асинхронную генерацию новой пачки абсурдных дел через подключенную языковую модель.

* Тело запроса (JSON, опционально):
```json
{
  "count": 5
}
```
* Процесс генерации выполняется в фоне с учетом осей вариативности и дедупликации заголовков по Жаккару.

---

## 4. Служебные эндпоинты и мониторинг

### GET /api/status
Возвращает полную сводку о текущем состоянии сервера, таймингах, ошибках модерации и статусе внешних подключений.

Пример ответа:
```json
{
  "state": "idle",
  "case_title": "",
  "defendant": "",
  "charge": "",
  "time_left_sec": 0,
  "chat_mod_error": "",
  "integrations": {
    "twitch": true,
    "donationalerts": true,
    "donatepay": false
  }
}
```

---

### POST /api/donate
Универсальный вебхук для приема пожертвований из сторонних систем (StreamElements, Streamlabs и др.).

* Тело запроса (JSON):
```json
{
  "donor": "Иван",
  "amount": 250,
  "currency": "RUB",
  "message": "Свидетель заявляет, что подсудимый невиновен!"
}
```

## 5. Протокол WebSocket (/ws)

Сервер обслуживает двустороннее WebSocket соединение по адресу `ws://localhost:7890/ws`.

### Исходящие события сервера (Server -> Client):
* `state_change`: смена текущей фазы суда (`idle`, `indictment`, `testimony`, `defense`, `objection`, `deliberation`, `verdict`), передача таймера и информации о деле.
* `subtitles`: реплика судьи, текст для титров и текущая анимация персонажа.
* `testimony`: сообщение подсудимого из чата для отображения на плашке оверлея.
* `verdict`: итоговое решение суда, голоса, назначенная мера наказания и твист взятки.
* `donation`: уведомление о донате и приобщении показаний свидетеля.
* `panic`: широковещательный сигнал немедленного сброса интерфейса оверлея.

### Входящие команды клиента (Client -> Server):
* `{"action": "ping"}`: поддержание активности соединения, сервер отвечает `{"type": "pong"}` с измерением RTT.
* `{"action": "panic"}`: отправка сигнала тревоги.
* `{"action": "defense", "payload": {"text": "..."}}`: передача речи защиты стримера.
* `{"action": "animation", "payload": {"name": "slam"}}`: запуск анимации удара молотка в оверлее.
