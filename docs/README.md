# Центр документации Stream Tribunal

[← Вернуться к главному README](../README.md)

Полный комплект технической и пользовательской документации для стримеров, модераторов каналов и разработчиков.

---

## Маршруты по ролям

### Для стримеров (Быстрый старт эфира)
1. [Установка и запуск на Windows (один .exe файл)](INSTALL.md): системные требования, экспресс-запуск без окружения, чеклист неполадок.
2. [Настройка оверлея и звука в OBS Studio](OBS_SETUP.md): добавление браузерного оверлея, маршрутизация звука в наушники, горячие клавиши паники и аварийная сцена.
3. [Полный справочник конфигурации](CONFIGURATION.md): подключение ключей нейросетей, настройка синтеза речи Silero и Edge, пороги донатов и взятки.
4. [Модерация и безопасность трансляции](MODERATION_AND_SAFETY.md): почему включен ban_confirm, как работает кнопка паники и защита от prompt-инъекций.

### Для модераторов чата
1. [Модерация и правила Twitch](MODERATION_AND_SAFETY.md): команды чата, работа с очередью подсудимых, ручная блокировка через пульт управления.
2. [Справочник конфигурации](CONFIGURATION.md): списки быстрых статей обвинения и колода наказаний для стримера.

### Для разработчиков и интеграторов
1. [Сборка из исходников и архитектура](INSTALL.md#5-сборка-из-исходников-для-разработчиков): компиляция бинарника на Go, сборка React пульта и запуск тестов.
2. [Архитектура системы](ARCHITECTURE.md): модульное устройство, жизненный цикл судебного заседания, потоковый чанкер речи и память рецидивистов.
3. [Справочник REST и WebSocket API](API_REFERENCE.md): спецификация эндпоинтов, формат авторизации, события WebSocket шины оверлея.
